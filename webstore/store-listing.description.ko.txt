클릭 한 번으로 현재 보고 있는 페이지의 캐시를 삭제한 뒤 새로고침하는 Chrome 확장 프로그램입니다.
일반적인 강력 새로고침(Ctrl+Shift+R)으로는 남아 있는 Service Worker 등록과 CacheStorage도 함께 삭제하므로,
웹 개발과 디버깅 시 캐시된 오래된 파일을 피해 최신 상태를 확인할 수 있습니다.

■ 주요 기능

・클릭 한 번으로 딥 클린 새로고침
  도구 모음의 아이콘을 클릭하면 현재 보고 있는 페이지에 대해 다음 작업을 수행합니다.
  1. 페이지 출처(origin)의 Service Worker 등록과 CacheStorage 삭제
  2. 같은 출처의 HTTP 캐시 삭제 시작
  3. 캐시를 우회하여 페이지 새로고침
  캐시 삭제에 실패한 경우에도 새로고침은 수행합니다.

・모든 탭 한꺼번에 클린 새로고침
  도구 모음의 아이콘을 마우스 오른쪽 버튼으로 클릭 → "모든 탭 클린 새로고침"을 선택하면, 열려 있는 모든 탭에 대해
  각 출처의 캐시를 삭제한 뒤 새로고침합니다(아래의 지원되지 않는 페이지 제외).

・모든 백그라운드 탭 강제 절전
  도구 모음의 아이콘을 마우스 오른쪽 버튼으로 클릭 → "모든 백그라운드 탭 강제 절전"을 선택하면,
  표시되지 않는 탭을 메모리에서 해제합니다. 탭은 닫히지 않으며, 다음에 선택할 때 자동으로 새로고침됩니다.
  각 창에서 표시 중인 탭은 대상에서 제외됩니다.

・DNS 캐시 삭제 화면 열기
  도구 모음의 아이콘을 마우스 오른쪽 버튼으로 클릭 → "DNS 캐시 삭제 화면 열기"를 선택하면, 브라우저 내 DNS 캐시
  화면을 새 탭에서 엽니다. 화면의 "Clear host cache"를 누르면 삭제할 수 있습니다.
  일반 클린 새로고침에서는 DNS 캐시를 삭제하지 않습니다.

・데이터 수집·외부 통신 없음
  열람 데이터를 수집하거나 외부로 전송하지 않습니다. 설정 화면도 없어 설치하자마자 바로 사용할 수 있습니다.

■ 삭제 범위와 지원되지 않는 페이지

・캐시 삭제는 출처(프로토콜·호스트·포트의 조합) 단위로 이루어집니다.
  같은 출처의 다른 페이지 캐시도 삭제됩니다.
・쿠키·로그인 상태·열람 기록·비밀번호 등 캐시 이외의 데이터는 삭제하지 않습니다.
・브라우저 설정 화면이나 확장 프로그램 페이지 등 브라우저 내부 페이지는 클린 새로고침 대상이 아닙니다.
・로컬 HTML 파일(file:)은 캐시를 삭제하지 않고, 캐시를 우회한 새로고침만 수행합니다.
・클릭 시 아이콘에 표시되는 "✓"는 처리 시작을 나타내는 표시이며, 삭제 성공을 의미하지 않습니다.

■ 이런 분께 추천합니다

・웹 개발자: CSS / JavaScript 변경이 캐시 때문에 반영되지 않을 때
・PWA 확인: 오래된 Service Worker나 캐시가 남아 최신 버전이 표시되지 않을 때
・일반 사용자: 페이지 표시가 이상할 때 새로 고치는 용도

■ 사용 방법

1. 새로고침하려는 페이지에서 도구 모음의 아이콘을 클릭합니다.
2. 모든 탭을 한꺼번에 처리하려면 아이콘을 마우스 오른쪽 버튼으로 클릭하고 "모든 탭 클린 새로고침"을 선택합니다.
3. 표시되지 않는 탭의 메모리를 해제하려면 아이콘을 마우스 오른쪽 버튼으로 클릭하고
   "모든 백그라운드 탭 강제 절전"을 선택합니다.

■ 권한 안내

・activeTab: 클릭했을 때 현재 보고 있는 탭의 URL을 가져오는 데 사용합니다.
・browsingData: Service Worker 등록, CacheStorage, HTTP 캐시를 삭제하는 데 사용합니다.
・contextMenus: 아이콘의 마우스 오른쪽 버튼 메뉴에 "모든 탭 클린 새로고침", "모든 백그라운드 탭 강제 절전",
  "DNS 캐시 삭제 화면 열기" 항목을 추가하는 데 사용합니다.
・tabs: 모든 탭의 URL을 가져와 캐시를 삭제하고, 새로고침이나 메모리 해제를 수행하는 데 사용합니다.
