這是一款 Chrome 擴充功能，只需一鍵，即可刪除目前頁面的快取並重新載入。
它還會一併刪除一般強制重新整理（Ctrl+Shift+R）無法清除的 Service Worker 註冊和 CacheStorage，
因此在 Web 開發和除錯時，可以避開快取的舊檔案，查看最新狀態。

■ 主要功能

・一鍵徹底重新整理
  點擊工具列圖示，將對目前頁面執行以下操作：
  1. 刪除該頁面來源（origin）的 Service Worker 註冊和 CacheStorage
  2. 開始清除同一來源的 HTTP 快取
  3. 繞過快取重新載入頁面
  即使快取清除失敗，也會重新載入頁面。

・一次徹底重新整理所有分頁
  在工具列圖示上按右鍵 →「徹底重新整理所有分頁」，即可清除每個來源的快取，然後重新載入
  所有已開啟的分頁（下述不支援的頁面除外）。

・強制所有背景分頁進入休眠
  在工具列圖示上按右鍵 →「強制所有背景分頁進入休眠」，即可從記憶體中釋放未顯示的分頁。
  分頁不會被關閉，下次選取時會自動重新載入。
  各視窗中正在顯示的分頁不在處理範圍內。

・開啟 DNS 快取清除頁面
  在工具列圖示上按右鍵 →「開啟 DNS 快取清除頁面」，即可在新分頁中開啟瀏覽器內的 DNS 快取
  頁面。點擊頁面中的「Clear host cache」即可清除。
  一般的徹底重新整理不會清除 DNS 快取。

・不蒐集資料，無外部通訊
  不會蒐集瀏覽資料，也不會傳送到外部。沒有設定畫面，安裝後即可使用。

■ 清除範圍與不支援的頁面

・快取依來源（通訊協定、主機和連接埠的組合）清除。
  同一來源下其他頁面的快取也會被清除。
・Cookie、登入狀態、瀏覽記錄、密碼等快取以外的資料不會被刪除。
・瀏覽器設定頁面和擴充功能頁面等瀏覽器內部頁面不支援徹底重新整理。
・對於本機 HTML 檔案（file:），不會清除快取，只會繞過快取重新載入。
・點擊時圖示上顯示的「✓」表示處理已開始，並不表示清除成功。

■ 推薦給這些使用者

・Web 開發者：CSS / JavaScript 的修改因快取而沒有生效時
・檢查 PWA：舊的 Service Worker 或快取殘留，無法顯示最新版本時
・一般使用者：頁面顯示異常時用來重新整理

■ 使用方法

1. 在想要重新載入的頁面上，點擊工具列圖示。
2. 要一次處理所有分頁時，在圖示上按右鍵，選擇「徹底重新整理所有分頁」。
3. 要釋放未顯示分頁的記憶體時，在圖示上按右鍵，選擇
   「強制所有背景分頁進入休眠」。

■ 關於權限

・activeTab：用於在點擊時取得目前顯示分頁的 URL。
・browsingData：用於刪除 Service Worker 註冊、CacheStorage 和 HTTP 快取。
・contextMenus：用於在圖示的右鍵選單中新增「徹底重新整理所有分頁」「強制所有背景分頁進入休眠」和
  「開啟 DNS 快取清除頁面」。
・tabs：用於取得所有分頁的 URL 並清除快取，然後重新載入或釋放記憶體。
