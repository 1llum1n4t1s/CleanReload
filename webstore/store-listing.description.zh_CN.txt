这是一款 Chrome 扩展程序，只需一键，即可删除当前页面的缓存并重新加载。
它还会一并删除普通强制刷新（Ctrl+Shift+R）无法清除的 Service Worker 注册和 CacheStorage，
因此在 Web 开发和调试时，可以避开缓存的旧文件，查看最新状态。

■ 主要功能

・一键彻底刷新
  点击工具栏图标，将对当前页面执行以下操作：
  1. 删除该页面来源（origin）的 Service Worker 注册和 CacheStorage
  2. 开始清除同一来源的 HTTP 缓存
  3. 绕过缓存重新加载页面
  即使缓存清除失败，也会重新加载页面。

・一次性彻底刷新所有标签页
  右键点击工具栏图标 →“彻底刷新所有标签页”，即可清除每个来源的缓存，然后重新加载
  所有已打开的标签页（下述不支持的页面除外）。

・强制所有后台标签页休眠
  右键点击工具栏图标 →“强制所有后台标签页休眠”，即可从内存中释放未显示的标签页。
  标签页不会被关闭，下次选中时会自动重新加载。
  各窗口中正在显示的标签页不在处理范围内。

・打开 DNS 缓存清除页面
  右键点击工具栏图标 →“打开 DNS 缓存清除页面”，即可在新标签页中打开浏览器内的 DNS 缓存
  页面。点击页面中的“Clear host cache”即可清除。
  普通的彻底刷新不会清除 DNS 缓存。

・不收集数据，无外部通信
  不会收集浏览数据，也不会向外部发送。没有设置界面，安装后即可使用。

■ 清除范围与不支持的页面

・缓存按来源（协议、主机和端口的组合）清除。
  同一来源下其他页面的缓存也会被清除。
・Cookie、登录状态、浏览历史记录、密码等缓存以外的数据不会被删除。
・浏览器设置页面和扩展程序页面等浏览器内部页面不支持彻底刷新。
・对于本地 HTML 文件（file:），不会清除缓存，只会绕过缓存重新加载。
・点击时图标上显示的“✓”表示处理已开始，并不表示清除成功。

■ 推荐给这些用户

・Web 开发者：CSS / JavaScript 的修改因缓存而没有生效时
・检查 PWA：旧的 Service Worker 或缓存残留，无法显示最新版本时
・普通用户：页面显示异常时用来刷新

■ 使用方法

1. 在想要重新加载的页面上，点击工具栏图标。
2. 要一次性处理所有标签页时，右键点击图标，选择“彻底刷新所有标签页”。
3. 要释放未显示标签页的内存时，右键点击图标，选择
   “强制所有后台标签页休眠”。

■ 关于权限

・activeTab：用于在点击时获取当前显示标签页的 URL。
・browsingData：用于删除 Service Worker 注册、CacheStorage 和 HTTP 缓存。
・contextMenus：用于在图标的右键菜单中添加“彻底刷新所有标签页”“强制所有后台标签页休眠”和
  “打开 DNS 缓存清除页面”。
・tabs：用于获取所有标签页的 URL 并清除缓存，然后重新加载或释放内存。
