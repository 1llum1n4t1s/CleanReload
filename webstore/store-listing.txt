【ストアの掲載情報】タブ
------------------------------------------------------------

■ 名前（30文字以内）
Clean Reload

■ 概要（132文字以内）
ワンクリックでキャッシュを完全クリアして再読み込み。全バックグラウンドタブの強制スリープにも対応します。

■ 説明（16,000文字以内）
ワンクリックで、開いているページのキャッシュを削除してから再読み込みするChrome拡張機能です。
通常のスーパーリロード（Ctrl+Shift+R）では残る Service Worker の登録や CacheStorage もまとめて削除するため、
Web開発やデバッグの際に、キャッシュされた古いファイルを避けて最新の状態を確認できます。

■ 主な機能

・ワンクリック ディープクリーンリロード
  ツールバーのアイコンをクリックすると、表示中のページについて次の処理を行います。
  1. ページのオリジンの Service Worker 登録と CacheStorage を削除
  2. 同じオリジンの HTTP キャッシュの削除を開始
  3. キャッシュをバイパスしてページを再読み込み
  キャッシュの削除に失敗した場合も、再読み込みは行います。

・全タブ一括クリーンリロード
  ツールバーのアイコンを右クリック →「全タブをクリーンリロード」で、開いているすべてのタブについて、
  各オリジンのキャッシュを削除してから再読み込みします（下記の対象外ページを除く）。

・全バックグラウンドタブを強制スリープ
  ツールバーのアイコンを右クリック →「全バックグラウンドタブを強制スリープ」で、
  表示していないタブをメモリから解放します。タブは閉じず、次に選択したときに自動で再読み込みされます。
  各ウィンドウで表示中のタブは対象外です。

・DNSキャッシュの削除画面を開く
  ツールバーのアイコンを右クリック →「DNSキャッシュの削除画面を開く」で、ブラウザ内の DNS キャッシュの
  画面を新しいタブで開きます。画面内の「Clear host cache」を押すと削除できます。
  通常のクリーンリロードでは DNS キャッシュは削除しません。

・データ収集・外部通信なし
  閲覧データの収集や外部への送信は一切行いません。設定画面もなく、インストールしてすぐ使えます。

■ 削除の範囲と対象外のページ

・キャッシュの削除はオリジン（プロトコル・ホスト・ポートの組み合わせ）単位です。
  同じオリジンの別のページのキャッシュも削除されます。
・Cookie・ログイン状態・閲覧履歴・パスワードなど、キャッシュ以外のデータは削除しません。
・ブラウザの設定画面や拡張機能のページなど、ブラウザ内部のページはクリーンリロードの対象外です。
・ローカルの HTML ファイル（file:）は、キャッシュを削除せず、キャッシュをバイパスした再読み込みだけを行います。
・クリック時にアイコンに表示される「✓」は処理開始の目印で、削除の成功を示すものではありません。

■ こんな方におすすめ

・Web開発者: CSS / JavaScript の変更がキャッシュのせいで反映されないときに
・PWA の確認: 古い Service Worker やキャッシュが残って最新版が表示されないときに
・一般の方: ページの表示がおかしいときのリフレッシュに

■ 使い方

1. 再読み込みしたいページで、ツールバーのアイコンをクリックします。
2. すべてのタブをまとめて処理するときは、アイコンを右クリックして「全タブをクリーンリロード」を選びます。
3. 表示していないタブのメモリを解放するときは、アイコンを右クリックして
   「全バックグラウンドタブを強制スリープ」を選びます。

■ 権限について

・activeTab: クリックしたときに表示中のタブの URL を取得するために使用します。
・browsingData: Service Worker の登録・CacheStorage・HTTP キャッシュを削除するために使用します。
・contextMenus: アイコンの右クリックメニューに、全タブのクリーンリロード・強制スリープ・
  DNSキャッシュ画面を開く項目を追加するために使用します。
・tabs: 全タブの URL を取得してキャッシュを削除し、再読み込みやメモリ解放を行うために使用します。

【プライバシーへの取り組み】タブ
------------------------------------------------------------

■ このアイテムに単一の目的はありますか？
はい

■ 単一の目的の説明
ワンクリックで、表示中のページのオリジンのキャッシュ（Service Worker・CacheStorage・HTTP キャッシュ）を削除して再読み込みする

■ データの使用に関する開示

  ・ユーザーデータを収集しますか？
    いいえ。個人を特定できる情報・健康に関する情報・財務状況や支払いに関する情報・認証に関する情報・
    個人的コミュニケーション・位置情報・ウェブ履歴・ユーザーのアクティビティ・ウェブサイトのコンテンツの
    9 種類はいずれも収集しません。

  ・ユーザーのデータをどのように扱いますか？
    - ユーザーデータの販売: しない
    - ユーザーデータの本来の目的以外への使用や転送: しない
    - 信用力の判定や貸付目的での使用や転送: しない

■ 権限の正当性

  activeTab:
  ユーザーがツールバーのアイコンをクリックしたときに、そのタブの URL からオリジンを特定し、そのオリジンのキャッシュを削除してタブを再読み込みするために使用します。ページへのスクリプト注入は行いません。

  browsingData:
  再読み込みするタブのオリジンに限定して、Service Worker 登録・CacheStorage・HTTP キャッシュを削除するために使用します。閲覧履歴・Cookie・パスワードなど他のデータは削除しません。

  contextMenus:
  ツールバーアイコンの右クリックメニューに「全タブをクリーンリロード」「全バックグラウンドタブを強制スリープ」「DNSキャッシュの削除画面を開く」の 3 項目を表示するために使用します。ページ上のコンテキストメニューには追加しません。

  tabs:
  「全タブをクリーンリロード」で全タブの URL を取得し、各オリジンのキャッシュ削除と再読み込みを行うために使用します。「全バックグラウンドタブを強制スリープ」で非アクティブなタブを列挙して破棄する際にも使用します。URL は処理後に破棄し、保存・外部送信は行いません。

■ プライバシーポリシー URL
https://cleanreload.kagayoi.com/privacy

■ リモートコードを使用していますか？
いいえ
