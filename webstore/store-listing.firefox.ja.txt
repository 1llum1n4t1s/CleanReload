■ 名前（50 文字以内）
Clean Reload

■ 概要 / Summary（250 文字以内）
ワンクリックで Service Worker・CacheStorage・HTTP キャッシュをクリアしてページを再読み込みするスーパーリロード拡張機能。全バックグラウンドタブの強制スリープにも対応。外部送信ゼロ・データ収集ゼロ。

■ 説明 / Description（16,000 文字以内）
ワンクリックでキャッシュを完全クリアしてページを再読み込みする拡張機能です。
Web 開発やデバッグの際に、キャッシュされた古いファイルを回避して最新の状態を確認できます。

■ 主な機能

・ワンクリック ディープクリーンリロード
  ツールバーのアイコンをクリックするだけで、Service Worker 登録・CacheStorage・HTTP キャッシュを削除してからページを再読み込みします。
  通常のスーパーリロード（Ctrl+Shift+R）ではクリアされない Service Worker キャッシュや CacheStorage も含めてリセットできます。

・全タブ一括クリーンリロード
  ツールバーのアイコンを右クリック →「全タブをクリーンリロード」で、開いている全タブのキャッシュを削除してリロードします。

・全バックグラウンドタブを強制スリープ
  ツールバーのアイコンを右クリック →「全バックグラウンドタブを強制スリープ」で、非アクティブなタブをメモリから解放します。タブは閉じず、次に選択したとき自動的に再読み込みします。各ウィンドウで表示中のアクティブタブは対象外です。

・軽量 & 最小権限
  バックグラウンドでのデータ収集や外部通信は一切行いません。

・こんな方におすすめ
  - Web 開発者: CSS / JS の変更がキャッシュで反映されない問題を即座に解決
  - デバッグ中: 常に最新のリソースでテストしたい方
  - 一般ユーザー: ページの表示がおかしい時にサッとリフレッシュ

■ 使い方

1. アドオンをインストール
2. リロードしたいページでツールバーのアイコンをクリック（単一タブ）
3. 全タブを一括リロードしたい場合はアイコンを右クリック →「全タブをクリーンリロード」
4. バックグラウンドタブをメモリから解放したい場合はアイコンを右クリック →「全バックグラウンドタブを強制スリープ」

■ Firefox 版での挙動について（重要）

Firefox の browsingData API は Chrome と仕様が異なります。本拡張機能は Firefox 上で次のように動作します。

・Service Worker 登録 / CacheStorage: 対象タブのホスト名単位で削除します（origin 単位の精密削除は Firefox が未対応のため、ホスト名単位にフォールバック）。
・HTTP キャッシュ: Firefox の removeCache API は対象オリジンを絞り込めない仕様のため、クリック時に Firefox 全体の HTTP キャッシュをクリアします（Chrome 版は該当オリジンのみ）。

いずれの場合も削除後にページを HTTP キャッシュバイパスで再読み込みします。クリック操作はユーザーの明示的な意思で行われるため、上記の挙動は意図したリセットの範囲内です。

■ プライバシー
すべてブラウザ内で完結し、外部サーバーへの通信・個人情報の収集は一切行いません。リモートコードの読み込みもありません。プライバシーポリシーは docs/privacy-policy.md を参照。
