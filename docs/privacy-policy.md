# プライバシーポリシー - Clean Reload

最終更新日: 2026年10月30日

## 概要

「Clean Reload」は、ユーザーのプライバシーを最大限に尊重する Chrome / Firefox 拡張機能です。

## データの収集

この拡張機能は、いかなる個人情報も収集、保存、送信しません。

## 使用する権限

### activeTab
ユーザーがツールバーのアイコンをクリックした際に、アクティブなタブのみにアクセスするために使用します。バックグラウンドでのデータアクセスは一切行いません。

### browsingData
Service Worker 登録と HTTP キャッシュを削除し、Chrome では該当オリジンの CacheStorage も削除するために使用します。閲覧履歴や Cookie などの他のデータには一切アクセスしません。

> Firefox 版では browsingData API の仕様差により、Service Worker 登録は対象タブのホスト名単位で削除します。この削除に失敗した場合は、Firefox 全体の Service Worker 登録解除を試みます。HTTP キャッシュはブラウザ全体で削除されます。Firefox の browsingData API では CacheStorage（DOM Cache API）を削除できないため、保存済みの CacheStorage は残ります（閲覧履歴・Cookie・パスワード等には一切アクセスしません）。

### contextMenus
ツールバーのアイコンを右クリックした際に「全タブをクリーンリロード」と「全バックグラウンドタブを強制スリープ」のメニュー項目を表示するために使用します。Chromium 系ブラウザでは「DNSキャッシュの削除画面を開く」も表示し、開いた画面でユーザーが手動で削除します。Firefox ではこの DNS メニューは表示しません。ページ上のコンテキストメニューには一切追加しません。

### tabs
「全タブをクリーンリロード」機能で全タブのURLを取得してキャッシュを削除するほか、「全バックグラウンドタブを強制スリープ」機能で非アクティブなタブをメモリから解放するために使用します。Chromium 系ブラウザでは、DNS キャッシュを手動で削除するためのブラウザ内部画面を新しいタブで開く際にも使用します。取得したURL情報は処理完了後に破棄され、保存や外部送信は一切行いません。

## 外部通信

この拡張機能は、外部サーバーへの通信を一切行いません。すべての処理はブラウザ内で完結します。

## リモートコード

この拡張機能は、外部からのコード読み込みを一切行いません。すべてのコードは拡張機能パッケージ内に含まれています。
