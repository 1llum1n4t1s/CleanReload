WHY IT DIFFERS

スーパーリロードでは、

Clean Reload が削除するもの

Service Worker
該当オリジンの登録を解除してから再読み込みする
CacheStorage
Cache API に積まれたレスポンスを削除する
HTTP cache
ブラウザキャッシュを迂回して取得し直す
スコープ
対象は現在のオリジン。他サイトのデータには触れない

DevTools の Application タブを開いて手作業で消していた手順を、ツールバーのクリック 1 回に畳んでいます。

01

アイコンをクリック

確認中のタブで、ツールバーの Clean Reload アイコンを押します。設定画面を開く必要はありません。

02

オリジン単位で掃除

そのページのオリジンに紐づく Service Worker 登録・CacheStorage・HTTP キャッシュを削除します。

03

最新の状態で再読み込み

掃除が終わってからリロードするため、確実に最新のファイルで表示されます。

FEATURES

1 タブでも、
開いている全部でも。

右クリックメニューから全タブ一括のクリーンリロードも実行できます。検証環境をまとめて更新したいときに便利です。

  • ワンクリックのディープクリーンリロード
  • 右クリックから全タブ一括実行
  • 外部通信とデータ収集を行わない設計

DESIGN PRINCIPLES

LOCAL

外部に送らない

収集も送信もしません。処理はすべてブラウザの中で完結します。

SCOPED

オリジン単位で消す

対象は今見ているオリジンだけ。他サイトのキャッシュは巻き添えにしません。

MINIMAL

権限は必要な分だけ

常時の広域サイト権限を持たない構成で動作します。
